# 🛒 E-Commerce Sales Analysis & Dashboard

## 📊 Project Overview

This project is an **E-Commerce Sales Analysis Dashboard built entirely in Microsoft Excel**.

The project analyzes e-commerce order data to understand sales performance, profitability, customers, products, categories, payment methods, order status, shipping modes, ratings, and regional performance.

The final Excel workbook contains **1,018 order records and 28 columns**, with Pivot Tables and an interactive Dashboard for business analysis.

---

## 🎯 Project Objectives

- Analyze overall e-commerce sales performance
- Track total orders, sales, profit, customers, and average order value
- Identify top-performing products
- Analyze sales by category and sub-category
- Understand monthly sales trends
- Compare sales across different states
- Analyze customer performance
- Understand payment and shipping methods
- Analyze order status such as delivered, cancelled, and returned
- Monitor customer ratings
- Build a professional Excel dashboard for decision-making
